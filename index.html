Ask yourself

  1. Same meaning? It names the same thing as the English word, not something narrower or broader. Tap "See example images" if you're unsure what the place looks like.
  2. Natural? Would a Bangladeshi person really say or write this?
  3. Right style? Formal = textbook or newspaper Bangla. Colloquial = everyday speech.
  4. Correct spelling?
  5. Banglish (Bangla in English letters): is this how people type it on Facebook or Messenger? If people really use the English word (like "airport"), Accept and add a comment.
